# Backups

Guarde aqui cópias das fontes originais e exportações, fora do fluxo do site:
- `fontes-originais/` — PDFs, DOCX, PPTX originais.
- `exportacoes-notebooklm/` — áudios/vídeos/mapas exportados do NotebookLM.
- `versoes-antigas/` — versões anteriores de conteúdo.

Os materiais originais deste projeto estão nas pastas `Audios/`, `Vídeos/`, `Fontes/`, `Slides/`,
`Exercícios/` e `resumos/` na raiz, e as cópias servidas pelo site ficam em `public/arquivos/`.
