- **To / In order to / So as to** + **verbo** (forma básica).
- **In order not to / So as not to** + **verbo** (negativo).
- **For** + **substantivo** (ou **-ing** para função de objeto).
- **So that** + **sujeito + modal** (can/could/will/would) — obrigatório quando o sujeito muda.

**Decida pelo que vem depois:** verbo → *to*; substantivo → *for*; oração → *so that*.
