<BlocoPegadinha titulo="“For to talk” — errado">
Nunca use **for** antes de um verbo no infinitivo. Para propósito com verbo, use só **to**:
*I went out ~~for to~~ talk* → *…**to** talk*.
</BlocoPegadinha>

<BlocoPegadinha titulo="“For talk” — errado">
**For** exige **substantivo** ou **-ing**. *For ~~talk~~* → *for **a talk*** (substantivo) ou *for **talking***.
</BlocoPegadinha>

<BlocoPegadinha titulo="“So that understand” — falta sujeito + modal">
*So that* precisa de **sujeito + modal**: *so that **you can** understand*.
</BlocoPegadinha>

<BlocoPegadinha titulo="“In order to not forget” — ordem errada">
A forma negativa é **in order not to** (e **so as not to**), não *in order to not*.
</BlocoPegadinha>
