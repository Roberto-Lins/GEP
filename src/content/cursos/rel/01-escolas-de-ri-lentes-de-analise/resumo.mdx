- **Teoria = lente**, não definição a decorar. A pergunta é "qual lente explica melhor *este* caso?".
- **Realismo** (Hobbes): anarquia, *self-help*, poder, **dilema de segurança**. Para EUA-China,
  Ártico, corrida armamentista.
- **Liberalismo** (Kant/Locke): instituições, comércio, interdependência — com **lado sombrio**
  (integração vira arma). Para ONU, OMC, IMO, CNUDM, clima.
- **Construtivismo** (Wendt): "a anarquia é o que os Estados fazem dela"; ideias, identidade,
  **securitização**. Para guerra cognitiva, narrativas, legitimidade.
- **Use as três combinadas:** cada uma responde a uma pergunta diferente.
- **Brasil/Marinha:** Amazônia Azul = poder (realista) + CNUDM/ZOPACAS (liberal) + nome-securitização
  (construtivista). SN-BR como dissuasão.
- **Frase-matriz:** um ator busca poder com recursos materiais **e simbólicos**, alterando dependências
  e gerando consequências.
