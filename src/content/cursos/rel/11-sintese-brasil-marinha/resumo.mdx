- **A matéria é um só argumento:** lentes → sistema → ruptura → mar → recursos → segurança →
  globalização → governança → **Brasil-Marinha**.
- **Tese transversal:** a interdependência foi **"armada"** → **ruptura** da ordem, num sistema
  **unimultipolar**.
- **RI = disputa por poder** em oito formas: militar, econômico, energético, marítimo, ambiental,
  tecnológico, institucional, narrativo.
- **O mar é o ponto de convergência** de todas elas (para a Marinha).
- **Equação brasileira:** **CNUDM (razão) + Poder Naval/SN-BR (capacidade) = autonomia estratégica** →
  ser **sujeito**, não objeto.
- **As seguranças convergem:** energética, alimentar, ambiental, cibernética/cognitiva e marítima — todas
  atacáveis **sem guerra convencional**.
- **Frase de fechamento:** *o mundo atual não é apenas globalizado: é interdependente, competitivo,
  vulnerável e multidomínio.*
