Comparadores são a **ponte entre o analógico e o digital saturado**. Eles preparam o raciocínio para o
**Schmitt-trigger** e para o **555**.

<BlocoConceito titulo="A regra de ouro">
Em malha aberta, o amp-op **satura**: se `V+ > V−`, a saída vai para ≈ **+VCC**; se `V+ < V−`, vai
para ≈ **−VEE**. Nada de proporcional.
</BlocoConceito>
