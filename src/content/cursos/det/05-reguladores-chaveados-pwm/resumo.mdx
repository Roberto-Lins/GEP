- Transistor como **chave** (corte/saturação) → alta eficiência: V ≈ 0 ou I ≈ 0 quase sempre.
- `D = ton/T`; buck ideal: `VOUT = D·VIN`.
- Frequência constante; varia o **ton** para regular.
- Realimentação: `VFB ≈ VREF`; `VFB = VOUT·Rbaixo/(Rcima+Rbaixo)`.
- VOUT sobe → VFB sobe → duty cai; VOUT cai → duty sobe.
- Exemplo (slide): VIN=20 V, VREF=4 V, Rbaixo=8kΩ, Rcima=24kΩ → **VOUT=16 V, D=0,8**.
