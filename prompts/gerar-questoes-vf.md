# Prompt — Gerar questões de Verdadeiro/Falso (GEP P1)

Gere afirmações para julgar (V/F) no formato de `src/data/exercicios.ts`:
- `afirmacao`, `correta` (boolean), `comentario` justificando;
- metade aproximada verdadeira, metade falsa;
- as falsas devem conter um erro conceitual claro (troca de autor, inversão de definição, data errada).

Marque `topico` com o slug. Fontes: {COLE AQUI}
